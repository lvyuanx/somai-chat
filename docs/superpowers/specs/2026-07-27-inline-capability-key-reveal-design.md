# 能力 Key 输入框内查看设计

## 目标

能力管理卡片点击眼睛后，在 API Key 输入框自身显示完整明文，不再在输入框下方渲染额外文本。

## 交互规则

- 默认输入框使用密码类型，并以已保存的脱敏 Key 作为占位提示。
- 点击眼睛调用现有 reveal API；成功后输入框切换为文本类型，并显示完整 Key。
- 再次点击眼睛会清除浏览器内存中的明文，恢复密码输入框和脱敏占位。
- 仅查看明文不会产生待替换 Key，也不会在保存请求中携带 `api_key`。
- 用户在明文显示状态编辑输入框时，编辑后的值转为 `replacement_api_key`，后续保存才替换服务端 Key。
- 点击清除 Key 时同时清空查看值与待替换值，保持现有明确清除语义。

## 实现边界

`capability-state.js` 提供输入框显示值和输入事件转换的纯函数，确保查看值与替换值不会混淆。
`CapabilityManagement.vue` 使用显式 `model-value` 和输入处理器，不再以 `v-model` 直接绑定替换值，也删除下方
`revealed-secret` 元素。CSS 删除不再使用的明文行样式。

## 测试

- 查看状态下输入框值为明文。
- 查看但未编辑时，更新载荷不包含 `api_key`。
- 编辑已查看的明文后，更新载荷包含编辑后的 Key。
- 隐藏操作清除查看值，并恢复脱敏占位行为。
- Node 状态测试、Admin 页面集成测试、Vite 构建和完整 Python 质量门禁通过。
