# 调试台图片上传设计

## 目标

让 SOMAI 调试台直接选择本地图片并在当前消息中发送给 Qwen3-VL-Plus，同时保持 WebSocket 只传递文本协议与图片 URL。

## 方案

浏览器通过版本化 HTTP 接口 `POST /api/v1/images` 使用 `multipart/form-data` 上传单张图片。服务端仅接受 JPEG、PNG、WebP，按集中式配置校验上传字节数和解码像素数，生成随机文件名后写入进程本地临时目录。成功响应返回同源、不可猜测的 `image_url`；浏览器将其加入下一条 `message.create.data.image_urls`。

上传文件默认仅用于当前调试会话：服务端在启动时创建临时目录，在每次上传和应用退出时清理超过 TTL 的文件。未认证 MVP 不提供跨会话访问控制或持久保存；该接口仅适合单进程调试台，生产对象存储直传属于后续工作。

## 接口

`POST /api/v1/images`：字段名 `image`，返回 `201`：

```json
{"image_url":"/api/v1/images/img_<random>.png"}
```

`GET /api/v1/images/{image_id}`：仅提供仍在 TTL 内的已校验图片；未知或过期文件返回 404。上传不合法或超限时返回稳定的 400 错误，不暴露解码器细节。

## 调试台

输入框旁添加文件选择按钮与图片缩略预览。一次只选一张图片；替换选择会移除旧预览。上传进行时发送按钮禁用；上传成功后保持图片附件，发送成功后清空附件和预览。用户仍必须填写文本问题。浏览器不将 base64 或二进制塞入 WebSocket。

## 安全与测试

上传端点拒绝未知 MIME、伪造内容类型、过大文件、过大像素、空文件和多文件请求。文件名由服务器生成，原始文件名不落盘、不出现在日志。测试覆盖上传成功、格式与大小拒绝、过期清理、静态读取、前端发送 URL 与上传中的禁用状态。
