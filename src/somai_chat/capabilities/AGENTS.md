# Capabilities 模块

本模块定义天气、时间与联网搜索的固定配置模型，并通过 `CapabilityService` 管理数据库配置、加密密钥和运行时工具快照。

每轮对话只读取一次不可变工具快照。配置保存成功后原子替换当前快照，不影响已开始的生成。API Key 仅在服务内存中
短暂以明文存在，数据库只保存使用独立配置密钥加密的密文，公开列表只返回脱敏值。

`models.py` 定义边界模型和安全错误；`service.py` 负责首次导入、校验、持久化协调和工具构建。数据库访问必须通过
`admin.capability_repository`，能力模块不直接创建数据库会话或管理 HTTP 客户端生命周期。
